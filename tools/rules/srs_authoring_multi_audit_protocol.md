# 多層AI交差検証プロトコル

施行日: 2026-11-16

---

## 1. 監査対象および判定基準

本プロトコルは、アルバイト勤怠・給与管理SaaS（KINTAI）の要件定義書および実装コードの多層検証を標準化するものです。

- **C# 決定論的リンター (`VerifySRS.exe v1.2`)**: 波線、書式、DoD（定義完了条件）の機械式遮断。
- **OpenAI Codex CLI (`call_codex.ps1`)**: 読み取り専用サンドボックスによるコード・DDL境界検証およびHeavy Track初案執筆。
- **Anthropic Claude (`call_claude.ps1`)**: 労働基準法第37条割増計算、端数処理、並行性例外分岐の常時深層交差監査。
- **ローカル Qwen 27B (`call_qwen.ps1`)**: 自社GPU（RTX 5070 Ti）を活用した高速整合性・回帰チェック。

---

## 2. 判定区分 (Verdict)

- **PASS**: 指摘事項なし、または軽微な情報（Info）のみ。
- **WARN**: 仕様記述の補足や業務ルールの明確化が推奨される事項。
- **FAIL**: 法令違反、データ破損リスク、並行性デッドロック、セキュリティ脆弱性（P0/P1）。

すべてのFAIL項目は、コード改修およびテストコードによる実証証跡が提出されるまで解消と見なされません（Fail-Closed原則）。
