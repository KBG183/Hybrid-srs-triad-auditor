2. Files shorter than 2 bytes must not throw on BOM inspection.
3. UTF-32 LE (`FF FE 00 00`) begins with the UTF-16 LE BOM. A naive 2-byte check misclassifies it, which is harmless for skipping but should be an explicit decision.
4. The 0xFF 0xFE guard must run before any stripping, not after the buffer has been modified.
5.
